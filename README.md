# bookflips

Experiments. The main one is **[BookFlips](book-app/)**, an EPUB reader built for the Galaxy Z Fold 7: two-page spreads when the phone is open, one page on the cover screen, with page curls that follow your finger.

The first book made for it, an unofficial Kingdom Hearts companion, lives in its own repository: [kingdom-hearts-companion](https://github.com/fredwebs123-png/kingdom-hearts-companion).
